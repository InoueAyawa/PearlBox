PearlBox объединяет майнеры, пулы, настройку GPU, обновления и локальный кошелёк в одном приложении для Windows. Укажите свой адрес выплат PRL и имя воркера, выберите майнер и пул — и запускайте майнинг.

**Майнер и версия → Совместимый пул → Адрес выплат → Запуск майнинга**

Описание соответствует клиенту **0.9.8**.

## Основные возможности

| Возможность | Что это даёт |
| --- | --- |
| **Подготовка и запуск в один клик** | Автоматический подбор совместимых пулов для майнера. Недостающие версии скачиваются, проверяются и устанавливаются. BAT-файлы и параметры запуска не нужны. |
| **Управление версиями** | Выбор версии майнера, просмотр изменений, прогресса и скорости загрузки. Обновление текущей версии или отдельное хранение старых версий майнеров. |
| **Наглядный мониторинг** | Общий хешрейт на главной панели, состояние GPU закреплено над журналом. Распознаются принятые и отклонённые шары, а также состояние подключения. |
| **Настройка GPU по моделям** | Обнаружение дискретных видеокарт и группировка одинаковых моделей. Профили заполняют минимальную и максимальную частоты ядра, смещение, частоту памяти и мощность; применение требует подтверждения. |
| **Локальный кошелёк и зашифрованные копии** | Создание кошелька рядом с полем адреса, экспорт зашифрованной копии и локальное восстановление. Пароль и сид-фраза обрабатываются на вашем компьютере. |

### Обновления с сохранением выбора

- **Клиент:** центр обновлений предлагает последнюю версию и сохраняет локальные данные кошелька и настройки.
- **Майнеры:** новая версия может заменить текущую, а старые можно хранить отдельно. Встроенный PearlFortune также обновляется.
- **Загрузка:** отображаются прогресс и скорость, прерванная загрузка повторяется. Докачка доступна при поддержке сервера; установка выполняется после проверки файла.
- **Уведомления:** одинаковая или более старая версия не вызывает предложения обновиться. Пропущенную версию можно установить вручную.

## Быстрый старт

1. **Скачайте и откройте**  
   Загрузите EXE для Windows из раздела **Releases** этого репозитория и запустите его. Подтвердите запрос прав администратора Windows при запуске.

2. **Выберите и настройте**  
   Укажите майнер, версию и пул, затем свой **адрес выплат PRL** и имя воркера. Если кошелька ещё нет, нажмите **«Создать кошелёк»** рядом с адресом и сначала сохраните сид-фразу и зашифрованную резервную копию.

3. **Начните майнинг**  
   Нажмите **«Начать майнинг»**. Недостающее ПО будет подготовлено перед запуском. Следите за хешрейтом и журналом на главной панели; для завершения используйте кнопку остановки майнинга.

Настройка GPU выполняется отдельно и требует ручного подтверждения. Запуск при входе в систему и автоматический майнинг по умолчанию выключены; включить их можно в дополнительных настройках. Автоматический запуск майнинга не применяет параметры разгона.

### Требования

- Windows 10 / 11, 64-разрядная версия.
- Microsoft Edge WebView2 Runtime; если компонент отсутствует, следуйте подсказке приложения.
- Оборудование и драйверы, поддерживаемые выбранным майнером. Настройка GPU сейчас доступна для поддерживаемых дискретных карт NVIDIA; для других производителей в основном предусмотрено обнаружение устройств.

Один EXE — это формат распространения. Компоненты, майнеры и данные подготавливаются на компьютере, поэтому занятое место превышает размер скачанного файла.

## Кошелёк

Пароли кошелька, сид-фразы и закрытые ключи обрабатываются локально и не отправляются на сервер конфигурации. Сохраняйте собственные резервные копии. Для переводов восстановите кошелёк в [официальном приложении Pearl](https://github.com/pearl-research-labs/pearl).

## Примечания

- Допустимые частоты, смещение и мощность зависят от GPU и драйвера. Хешрейт профиля — ориентир; оценивайте стабильную работу своей системы.
- Отсутствующие или устаревшие показатели отображаются как «—».
- Остановите майнинг перед установкой или удалением майнеров и обновлением клиента. После перемещения EXE заново включите запуск при входе, чтобы обновить путь.
- Текущий выпуск — клиент для Windows, поддерживающий только PRL.
